Xxrun is a creative execution environment where running code generates evolving visual output — each variable mutation, loop iteration, and function call mapped to parameters driving a generative canvas that updates in real time.

### Core Capabilities

- **Live Variable Binding:** Scalar and array values from the running program are automatically bound to generative parameters (position, color, opacity, scale) without manual wiring.
- **Execution Replay:** Full execution trace replay lets creators scrub through a program's runtime history as if it were a timeline, re-rendering the canvas at any recorded state.
- **Export Snapshots:** Freeze any frame of the generative output to SVG or PNG — capturing program state as a permanent artifact.
