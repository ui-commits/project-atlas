Voluble Babka is a personal knowledge interface combining structured markdown note management with an LLM-assisted synthesis layer — enabling search, cross-linking, and thematic summaries across an evolving personal corpus without requiring a rigid taxonomy up front.

### Core Capabilities

- **Layered Markdown Editor:** A distraction-free editor with frontmatter-aware syntax highlighting, tag inference, and automatic backlink detection across the local note corpus.
- **LLM Synthesis Layer:** On-demand summarization and thematic clustering using a locally-routed LLM — surfacing conceptual neighbors and suggesting connections between notes without altering the source text.
- **Graph View:** Force-directed link graph rendering backlink density and co-occurrence clusters, making the structure of a personal knowledge base visually navigable.
