Neo UI Kit is a high-contrast, accessibility-engineered design system designed specifically for mission-critical agentic telemetry, live execution streams, and LLM operations interfaces.

### Features

- **Strict TypeScript Typing:** Full compile-time safety across component props, tokens, and telemetry data models.
- **Accessible Density:** High information density balanced against strict WCAG contrast compliance.
- **Operational Components:** Specialized primitives for execution traces, token consumption, status beacons, and structured log streams.
