Neon Sky Audio Player is a rich audiovisual interface engineered around real-time Web Audio API signal processing, frequency visualization, and boot-sequence interaction design.

### Core Capabilities

- **Audio Signal Analysis:** Frequency-spectrum analyzer and waveform rendering running on 60fps canvas animation loops.
- **Master-Bus DSP:** Virtual dynamics limiter, gain staging, and playback graph controls.
- **Atmospheric Boot Sequence:** Cohesive audiovisual initialization with retro-futuristic terminal aesthetics.
